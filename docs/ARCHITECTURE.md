# 아키텍처 및 데이터 흐름도

```text
[데이터 원천]
  ├─ yfinance : 시세 / 재무 수치
  └─ 증권사 리포트 컨센서스 : 목표주가 · 투자의견 분포 · 실적 추정치 · 의견 변경 이력
                    │
                    ▼
     [src/collectors/] (데이터 수집) ──► [src/types/] (스키마 검증 및 정합성 보장)
                    │
                    ▼
     [src/indicators/] (지표 계산)   ──► 순수 기술적/기본적 지표 계산 (점수화 절대 금지)
                    │
                    ▼
     [src/dashboard/]  (대시보드 표출) ──► Streamlit 기반 표/차트로 정직하게 시각화
```

### 모듈별 역할 및 책임
- `src/types/`: 데이터 무결성과 정합성을 강제하는 Pydantic 모델 정의.
- `src/collectors/`: 주가 시세, 재무제표 수치, 증권사 리포트 컨센서스, 기업 내러티브를 수집하는 모듈.
- `src/indicators/`: 이동평균선 이격도, 52주 고점 대비 낙폭(MDD), RSI 등 순수 수학적 지표 계산.
- `src/dashboard/`: 필터링, 표 조회, 핵심 지표 카드 등 UI 화면 표출.

## 증권사 리포트 데이터 취급 원칙

증권사 리포트는 크게 **원문(PDF·본문)** 과 **컨센서스(정형 수치)** 로 나뉜다.
본 프로젝트는 자동 수집 가능하고 정합성 검증이 되는 **컨센서스 수치만** 파이프라인으로 다룬다.

| 구분 | 항목 | 처리 방식 |
| --- | --- | --- |
| 컨센서스 (자동 수집) | 목표주가(평균/최고/최저/중앙), 투자의견 분포, 커버리지 애널리스트 수, 실적 추정치, 투자의견 변경 이력 | `src/collectors/analyst_reports.py`가 수집 |
| 리포트 원문 (수동) | 투자 포인트, 리스크 요약 | `NarrativeData`에 사람이 직접 입력 (저작권상 원문 자동 수집·저장 금지) |

### 점수화 금지 원칙과의 경계 (중요)
투자의견·목표주가는 **외부 기관이 산출해 공표한 값**이다. 따라서 다음 경계를 지킨다.

- ✅ **허용**: 출처가 매긴 수치를 **가공 없이 그대로 전달(pass-through)**. 값의 출처와 기준일을 함께 표기한다.
- ❌ **금지**: 그 값들을 재료로 우리가 **자체 점수·등급·종합 지수를 파생**시키는 행위.
  (예: 목표주가 괴리율과 투자의견 분포를 합성해 "매수 매력도 78점"을 만드는 것)

즉 "애널리스트 평균 목표주가 $210, 커버리지 42명"은 표시 가능하고,
"이를 종합한 자체 투자 점수"는 만들지 않는다.

### 데이터 정합성 규칙
- 원천에 값이 없으면 추정하지 않고 `None`으로 채운다.
- 수집 자체가 실패한 경우(네트워크·심볼 오류)와 "값이 원래 없는 경우"를 구분한다.
  전자는 오류로 수집자에게 보고하고, 후자만 `None`으로 남긴다.
  둘을 뭉뚱그리면 장애 상황이 `N/A`로 위장되어 표시되기 때문이다.
